📄 Scanner Agent Download

Easy setup to automatically upload scanned documents

Step 1: Download
Click the button below to download the setup file:
⬇️ Download Scanner Setup
File: scanner-setup.bat
Step 2: Install
1. Double-click the downloaded scanner-setup.bat file
2. Enter the server URL (or press Enter for default)
3. Wait for "Setup Complete!" message
4. Press any key to exit
Step 3: Authenticate
Option A (Recommended):
Log in to the DMS web interface. The frontend will automatically send your authentication token to the agent.

Option B (Manual):
Run the set-token command:
npm run set-token -- --token <YOUR_TOKEN> --userId <USER_ID> --userEmail <EMAIL>
Step 4: Start Scanner
1. Find agent.bat in the same folder
2. Double-click to run it
3. A command window will open showing "Watching for scans..."
4. Leave it running (minimize if you want)
Step 5: Auto-Start (Optional)
When you first run agent.bat, it will ask: "Install to Windows startup? (Y/N)"
Type Y and press Enter.

The scanner will now start automatically every time you log into Windows.
Step 6: Use It!
Save your scanned files to:

C:\Users\[YourName]\Documents\Scan

The scanner will automatically detect and upload them to the system.

Supported formats: PDF, JPG, PNG, TIFF, BMP, DOC, DOCX
Max file size: 100 MB
⚠️ Windows Security Warning If Windows shows a security warning, click "More info" → "Run anyway". This file is safe - it's your company's document scanning tool.

🔧 Troubleshooting

  • "No token set": Authenticate via the web frontend or use npm run set-token to provide a token manually.
  • Not uploading: Make sure agent.bat is running. Check for the command window in your taskbar. Verify token at http://localhost:4001/status.
  • Auto-start not working: Press Win+R, type shell:startup, press Enter. Copy agent.bat to that folder.
  • Error logs: Check the scanner.log file in the agent folder.
